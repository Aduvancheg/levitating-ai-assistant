# ИНЖЕНЕРНОЕ РУКОВОДСТВО: СБОРКА И ПАЙКА АКТИВНОГО АГЕНТА (v3.0)
**Проект «Antigravity» — Активная левитирующая сфера v5.3 (Ultralight)**

Это руководство содержит подробные физические схемы, рекомендации по монтажу и правила распределения веса бортовой корзины Агента в пределах жесткого **лимита массы 75 грамм**.

---

## РАЗДЕЛ 1. АППАРАТНАЯ АРХИТЕКТУРА И «СЛОЕНЫЙ ПИРОГ» АГЕНТА (УЗЕЛ 2)

Чтобы сфера левитировала абсолютно стабильно, не совершала хаотичных кувырков и мгновенно выравнивалась, все компоненты внутри корпуса должны быть размещены в виде строго сбалансированного «слоеного пирога»:

```
                       [ Северный Полюс ]
                   ┌────────────────────────┐
                   │    ESP32-CAM Board     │  ◄── Антенна направлена строго вверх
                   └───────────┬────────────┘
                               │
                       [ Линия Экватора ]
                   ┌────────────────────────┐
                   │  BNO085 IMU Sensor     │  ◄── Соосно центру масс сферы
                   ├────────────────────────┤
                   │  LiPo Battery 902540   │  ◄── Самый тяжелый элемент (Центр тяжести)
                   └───────────┬────────────┘
                               │
                       [ Южный Полюс ]
                   ┌────────────────────────┐
                   │     Smart DC-Coil      │  ◄── Плоский блин вклеен в основание
                   ├────────────────────────┤
                   │     Qi Wireless RX     │  ◄── Тонкий приемник Qi-зарядки
                   └────────────────────────┘
```

### Правила развесовки:
1.  **Центр тяжести:** Должен быть занижен и находиться строго на вертикальной оси сферы. Для этого аккумулятор **LiPo 902540** (вес ~18 г) приматывается термостойким каптоновым скотчем в специальный паз центрального ложемента.
2.  **Соосность IMU:** Высокоточный гироскоп **BNO085** наклеивается на аккумулятор так, чтобы физический центр микросхемы полностью совпадал с центром масс сферы. Это исключит ложные центробежные ускорения в расчете углов Pitch и Roll.
3.  **Антенна Wi-Fi:** Штыревая антенна ESP32-CAM должна быть направлена строго вверх, в сторону от металлических катушек, для исключения экранирования радиосигнала.

## РАЗДЕЛ 2. ПРИНЦИПИАЛЬНАЯ СХЕМА КОММУТАЦИИ И ИНТЕРЛОКА СФЕРЫ (УЗЕЛ 3)

Электромагнитная катушка Агента Smart DC-Coil (60-мм блин, R ≈ 6-8 Ом) управляется бортовым MOSFET-ключом D4184 от аккумулятора напрямую. Схема снабжена твердотельным нормально-замкнутым (NC) реле **CPC1017N** для защиты Qi-приемника.

```
       [ + LiPo Battery (3.7V - 4.2V) ] ───┬────────────────────────────────┐
                                           │                                │
                                           ▼ [+]                            ▼
                                  ┌─────────────────┐             ┌─────────────────┐
                                  │  Плата IP5306   │             │  Smart DC-Coil  │
                                  │ (Зарядка / 5V)  │             │   (Конец А)     │
                                  └────────┬────────┘             └────────┬────────┘
                                           │                                │
                                           ▼ [VOUT 5V]                      ▼
                                  ┌─────────────────┐                       │
                                  │   ESP32-CAM     │                       │
                                  │ (VCC / Питание) │                       │
                                  └────────┬────────┘                       │
                                           │                                ▼ (Точка соединения)
      [ GPIO 12 (Out) ESP32 ] ─────────────┼──────────────┐        ┌─────────────────┐
                                           │              │        │  MOSFET D4184   │
                                           ▼              ▼        │  DRAIN (Сток)   │
                                  ┌─────────────────┐    [GATE]───►│ (Силовой ключ)  │
                                  │ Твердотельное   │              └────────┬────────┘
                                  │ NC-Реле CPC1017 │                       │
                                  └────────┬────────┘                       ▼
                                           │                               [GND]
                                           ▼
                                  ┌─────────────────┐
                                  │  Qi RX Charger  │
                                  │ (Линия Выхода)  │
                                  └─────────────────┘
```

*   **Диод Шоттки защиты:** В линию выхода VOUT модуля IP5306 последовательно впаивается быстродействующий диод **SS34**, предотвращающий обратный переток мощности от конденсаторов во время сильных впрысков тока.
*   **Глушитель просадок (Low-ESR):** Напрямую к выводам `5V` и `GND` платы ESP32-CAM припаивается электролитический Low-ESR конденсатор емкостью **470 мкФ 10V** для фильтрации просадок питания при активации Wi-Fi передатчика.

## РАЗДЕЛ 3. ПАССИВНАЯ ТЕРМОДИНАМИКА («ПЕЧНОЙ ЭФФЕКТ») СФЕРЫ v5.3

Внутри легкого герметичного корпуса сферы горячий процессор ESP32-CAM, контроллер заряда IP5306 и нагревающаяся катушка способны поднять температуру до критических **+70°C**, что вызовет расплавление пластика PETG и вздутие LiPo. 

Для охлаждения в корпусе сферы делаются **вентиляционные жабры конвекции**:

1.  **Нижние жабры (Вход воздуха):** Круговая сетка из 6 отверстий диаметром **1.5 мм** на самом южном полюсе сферы, прямо под катушкой.
2.  **Верхние жабры (Выход воздуха):** 4 радиальные прорези шириной **1.2 мм** и длиной **8 мм** на северном полюсе, вокруг объектива ESP32-CAM.
3.  **Физика конвекции:** Нагретый катушкой и процессором воздух устремляется вверх и выходит через верхние жабры, создавая разрежение. Это разрежение втягивает холодный воздух через нижние отверстия. Данный пассивный «печной эффект» удерживает температуру внутри сферы на безопасном уровне **не более +42°C** без утяжеления конструкции вентилятором.
