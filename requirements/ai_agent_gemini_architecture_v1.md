# АРХИТЕКТУРА МУЛЬТИМОДАЛЬНОГО ИИ-АГЕНТА GEMINI PRO v1.0
## Multimodal AI Companion Architecture & Tool Calling Specification (.docs/ai_agent_gemini_architecture_v1.md)

Данное руководство описывает архитектуру интеграции искусственного интеллекта Google Gemini Pro (1.5 Pro / 2.0 Flash) в комплекс **Antigravity**.

---

## 1. Ключевые архитектурные принципы

1. **Долговременная память (Long-Term Memory):**
   - Все диалоги и события сохраняются в базе данных SQLite `/var/log/antigravity/ai_history.db` на Raspberry Pi 5.
   - При перезапуске питания или перезагрузке сервера Агент сохраняет контекст прошлых сессий.
   - Раз в 50 сообщений применяется автоматическая суммаризация (Executive Summary) для предотвращения разрастания контекста.

2. **Автоматическая постоянная активация (Persistent Auto-Activation):**
   - Флаг активации `ai_enabled = True` и `GEMINI_API_KEY` сохраняются в зашифрованном файле `/etc/antigravity/ai_config.json`.
   - После однократного включения на странице UI ИИ-ассистент автостартует при каждом включении питания.

3. **Умная очистка кэша (Smart Cache Manager):**
   - Фоновый поток мониторит диск RPi 5. Когда временные лог-файлы и снимки калибровки занимают >50% диска, Агент вежливо запрашивает разрешение у пользователя на очистку.
   - Вызов функции `clear_temp_cache()` удаляет мусор, оставляя неприкосновенной базу историй общения `ai_history.db`.

4. **Мультимодальное зрение (Vision Inspection):**
   - Запрос пользователя «Что у меня на столе?» активирует Tool Call `inspect_surface(tilt_angle)`.
   - Агент наклоняется на заданный угол, делает кадр с камеры ESP32-CAM (OV2640) и передает изображение в Gemini Vision API.
   - Результат анализа возвращается пользователю и записывается в память.

## 2. Спецификация Tool Calling (Инструменты ИИ)

В Gemini API зарегистрированы следующие функции бэкенда FastAPI (`main_server-v11.py`):

```python
GEMINI_TOOLS = [
    {
        "name": "get_system_telemetry",
        "description": "Получить текущую физическую телеметрию Базы и Агента (высота Z, температура катушек, заряд LiPo, статус BIST)."
    },
    {
        "name": "set_levitation_height",
        "description": "Изменить целевую высоту левитации Агента (target_z в мм, диапазон 10..45 мм).",
        "parameters": {"target_z": {"type": "float"}}
    },
    {
        "name": "run_spatial_helix_animation",
        "description": "Запустить фигуру высшего пилотажа 'Пространственная спираль' (SPATIAL_HELIX)."
    },
    {
        "name": "execute_safe_shutdown",
        "description": "Запустить плавный спуск Агента и обесточить катушки (SAFE_SHUTDOWN)."
    },
    {
        "name": "inspect_surface",
        "description": "Наклонить сферу Агента на заданный угол, сделать снимок с камеры ESP32-CAM и проанализировать предметы на столе.",
        "parameters": {"tilt_angle_deg": {"type": "float"}}
    },
    {
        "name": "clear_temp_cache",
        "description": "Очистить временные лог-файлы и снимки калибровки, освободив диск RPi 5 без удаления истории диалогов."
    }
]
```

## 3. Трехэтапный Bring-Up панель в UI (`TEST-AI-01..03`)

На новой вкладке UI `AI Assistant` реализован диагностический виджет:

1. **`TEST-AI-01: API Sync Check`** — Тестовый микро-запрос к Gemini API (проверка API-ключа, интернета и задержки).
2. **`TEST-AI-02: Camera Check`** — Проверка захвата кадра с камеры ESP32-CAM (OV2640).
3. **`TEST-AI-03: Audio Loop Check`** — Тест аудио-тракта SPU-WM30 (воспроизведение тона 440 Гц и проверка отклика микрофона).

*Примечание:* Сбои в шагах 2 и 3 высылают предупреждение `WARNING`, выводят подробные логи ошибок, но **не блокируют работу текстового/голосового чата**!
