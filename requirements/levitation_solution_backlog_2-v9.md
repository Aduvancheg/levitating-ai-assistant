### РАЗДЕЛ 2: РАЗРАБОТКА ДЛЯ ЦЕНТРАЛЬНОГО МОЗГА (Raspberry Pi 5)

*   **RPI-1 (Асинхронный Core Loop):** Главный неблокирующий цикл ПИД-управления на `asyncio` со стабильной частотой **не менее 860 Гц** [Файлы: `main_server-v7.py`, `quality-v7.md` // Чек-лист: `RPI-CL-2`].
*   **RPI-9 (BIST Diagnostics Coordinator):** Реализация асинхронного координатора встроенного самотестирования, поочередно запускающего тесты `BIST-HW-01` - `BIST-HW-04` и блокирующего силовой выход ШИМ при отказе [Файлы: `main_server-v7.py`, `bringup_test_suite_v4.md` // Чек-лист: `WEB-CL-5`].
*   **RPI-10 (Safe Shutdown Pipeline) [NEW v7.0]:** Реализация асинхронного пайплайна безопасного выключения `execute_shutdown_pipeline()`. Обязательные шаги: плавный спуск сферы со скоростью 5 мм/с, размагничивание катушек базы за 2.0 секунды (20 шагов по 100 мс) для предотвращения ЭДС-выбросов, перевод Агента в режим пассивного сна, выставление глобального флага безопасности `safe_to_unplug = True` [Файлы: `main_server-v7.py`, `use_cases_and_e2e_scenarios-v2.md`, `bringup_test_suite_v4.md` // Чек-лист: `SHUTDOWN-CL-1`, `SHUTDOWN-CL-2`].

### РАЗДЕЛ 3: РАЗРАБОТКА ВЕБ-ИНТЕРФЕЙСА И API УПРАВЛЕНИЯ

*   **WEB-4 (BIST Logging, Retries & Bypass Modals):** Верстка адаптивных карточек BIST с выдвижными моноширинными лог-панелями ошибок, кнопками точечного ретрая `Retry` и двухфакторным модальным окном Bypass Double-Confirmation [Файлы: `index_html_template-v7.txt`, `main_server-v7.py` // Чек-лист: `WEB-CL-4`, `WEB-CL-5`, `WEB-CL-6`].
*   **WEB-5 (Emergency Power-Down UI UI) [NEW v7.0]:** Интеграция в шапку интерфейса высококонтрастной кнопки `TURN OFF`. При нажатии кнопка запрашивает подтверждение, запускает API-эндпоинт `/api/manage/shutdown` и блокирует экран полноэкранной темной заставкой-оверлеем с отображением шагов размагничивания. По завершении выводит зеленый баннер «SAFE TO UNPLUG» [Файлы: `index_html_template-v7.txt`, `main_server-v7.py` // Чек-лист: `SHUTDOWN-CL-2`].

### РАЗДЕЛ 4: ТЕСТИРОВАНИЕ И ВЕРИФИКАЦИЯ (QUALITY CONTROL)

*   **RP-10 (Firmware Slew-Rate Failsafe) [NEW v9.0]:** Реализация на уровне С++ прошивки RP2040-Zero (Core 0) независимого ограничителя скорости нарастания ШИМ (Slew Rate Limit = 10 ед/мс). Защищает MOSFET AOD4184A от ВЧ-ударов при сбоях связи. [Файлы: `quality-v9.md` -> `RP-CL-10`]
*   **RPI-11 (Software Slew-Rate Limiter) [NEW v9.0]:** Доработка главного цикла `core_loop_860hz()` на RPi 5 для ограничения изменения вектора ШИМ шагом в `slew_rate_limit = 10` единиц за такт (1.16 мс), сглаживая переходные токовые процессы. [Файлы: `main_server-v9.py`, `quality-v9.md` -> `RPI-CL-10`]
*   **HW-6 (TVS Rail Clamp Integration) [NEW v9.0]:** Установка защитного TVS-диода SMBJ12A параллельно силовой шине 8.0V для гашения выбросов Lenz's Law, возвращаемых диодами SS54. [Файлы: `base_power_assembly_guide-v5.md`, `quality-v9.md` -> `HW-CL-10`]
*   **TEST-8 (EMF di/dt Slew-Rate Stress Test) [NEW v9.0]:** Модульное и E2E тестирование в pytest, имитирующее мгновенный сброс Z уставки с 25мм до 0. Проверить, что скорость спада ШИМ-каналов физически зажата в пределах 10 единиц за итерацию, а спуск плавный.

*   **TEST-6 (BIST Failures & Retry Unit Tests):** Тестирование имитатора сбоев. Проверить перехват ошибок бэкендом, правильную выдачу кодов `ERR-BIST-...` и успешное прохождение ретрая после устранения ошибки.
*   **TEST-7 (Safe Power-Down E2E Test) [NEW v7.0]:** Верификация пайплайна отключения. Проверить, что скорость снижения `Target Z` строго равна 5 мм/с, ШИМ в конце шага равен ровно `[0, 0, 0, 0, 0]`, реле Агента возвращается в безопасное замкнутое состояние, а флаг `safe_to_unplug` переходит в `True`.
