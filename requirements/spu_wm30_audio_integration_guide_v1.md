# РУКОВОДСТВО ПО ПОДКЛЮЧЕНИЮ И ИНТЕГРАЦИИ USB-МИКРОФОНА SPU-WM30 v1.0
## Integrated USB Audio Subsystem Manual (.docs/spu_wm30_audio_integration_guide_v1.md)

Данный документ содержит полное физическое, аппаратное и программное руководство по интеграции конференц-микрофона/спикера **Spacetronik SPU-WM30** в состав левитационного комплекса **Antigravity**.

---

## 1. Аппаратное подключение и прокладка кабеля (Hardware Routing)

1. **Интерфейс:** Стандартный USB 2.0 (UAC — USB Audio Class).
2. **Коммутация:** Подключается непосредственно в нижний свободный разъем **USB 2.0 (черный)** или **USB 3.0 (синий)** платы Raspberry Pi 5.
3. **Прокладка кабеля в корпусе (`enclosure_architecture_v9.md`):**
   - В нижнем подиуме корпуса Базы (`Lower_Podium_V9`) предусмотрен специальный задний вырез **`USB_AUX_PASS_THROUGH_SLOT`** размером **`14.0 x 8.0 мм`** с радиусными фасками.
   - Штатный USB-кабель от SPU-WM30 заводится через этот вырез внутрь нижнего отсека базы и подключается к порту RPi 5.
   - Кабель не пережимается байонетным замком крышки и не мешает закручиванию нижнего подиума.
4. **Размещение SPU-WM30 (Фаза 4):**
   - Микрофон устанавливается на столе рядом с базой на расстоянии **10–30 см**.
   - Акустическая развязка: Встроенная резиновая подложка SPU-WM30 полностью гасит микровибрации от работы кулера 3010.

## 2. Системная конфигурация Linux ALSA / PipeWire (Raspberry Pi OS Bookworm)

При подключении SPU-WM30 ядра Linux автоматически регистрируют UAC-устройство без установки внешних драйверов.

### Проверка идентификации в консоли:
```bash
# Проверка USB-устройства
lsusb | grep -i "audio"

# Список аудио-входов (Capture Devices)
arecord -l
# Ожидаемый вывод: card 1: Device [USB Audio Device], device 0: USB Audio [USB Audio]

# Список аудио-выходов (Playback Devices)
aplay -l
```

### Настройка уровней громкости (ALSA Config `/etc/asound.conf`):
```ini
pcm.!default {
    type asym
    playback.pcm {
        type plug
        slave.pcm "hw:1,0"
    }
    capture.pcm {
        type plug
        slave.pcm "hw:1,0"
    }
}
```

## 3. Программный аудио-драйвер Python (`AudioService` в `main_server-v11.py`)

Служба `AudioService` управляет записью и воспроизведением в асинхронном режиме через библиотеки `sounddevice` и `PyAudio`:

1. **Формат захвата речи:** 16,000 Гц, 16-бит PCM, Mono (стандарт для Google Gemini Multimodal Live API).
2. **Voice Activity Detection (VAD):** Использование библиотеки `webrtcvad` / `silero-vad` для автоопределения начала и конца фразы пользователя без нажатия кнопок.
3. **BIST-тест динамика и микрофона (`TEST-AI-03`):**
   - Воспроизведение короткого тестового тона (440 Гц, 0.5 сек) через динамик SPU-WM30.
   - Запись эхо-сигнала через встроенный 360° микрофон.
   - **Assert:** `assert max_amplitude > 0.05` (Проверка исправности аудио-тракта).
