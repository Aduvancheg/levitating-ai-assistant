# СТАНДАРТЫ КАЧЕСТВА И ЧЕК-ЛИСТЫ V10.0 (.docs/quality-v10.md)

## Дополнительные чек-листы v10.0:

### `RPI-CL-11` (Calibration FSM Safety)
- [x] Запрет любых маневров (`JOYSTICK`, `HELIX`) на шагах `PARKED`, `ZEROING`, `TAKEOFF_HOVER`, `WAIT_REMOVAL`.
- [x] Асинхронный таймаут безопасности 30.0 секунд при отсутствии клика оператора.
- [x] Плавный спуск со скоростью $\le 5.0\text{ мм/с}$ при отмене.

### `WEB-CL-9` (Calibration Wizard Modal)
- [x] Четкое модальное окно с пошаговой инструкцией и анимацией раздвижения подставки.
- [x] Кнопка "CONFIRM STAND REMOVED" становится активной только после перехода FSM в `WAIT_REMOVAL`.

### `HW-CL-11` (Split Cradle Mechanical Fit)
- [x] Зазор от внешнего края чашек катушек ($R = 38.5\text{ мм}$) до ножек подставки ($R = 56.5\text{ мм}$) равен не менее $18.0\text{ мм}$.
- [x] Глубина чаши 12.0 мм удерживает нижний торец сферы на высоте $+18.0\text{ мм}$ над крышкой.
