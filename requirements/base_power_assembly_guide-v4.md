# ИНЖЕНЕРНОЕ РУКОВОДСТВО: СБОРКА И ПАЙКА СИЛОВОЙ ПЛАТЫ БАЗЫ (GU22-13) v4.0
**Проект «Antigravity» — Фаза 4 (Макро-левитация до 25–50 см)**

Это руководство содержит подробные схемы, физическую трассировку и правила монтажа силового подиума Базы для работы с новыми увеличенными чашечными ферритами **PC40 GU22-13** и литцендратом **0.1x70**. 

---

## ⚠️ КРИТИЧЕСКИЙ ПРЕДОХРАНИТЕЛЬНЫЙ РЕГЛАМЕНТ
**Категорически запрещено пускать силовой ток питания катушек через плату Raspberry Pi 5!**
Импульсный ток пяти катушек базы достигает 7.5А в пиках. Тонкие дорожки цепей питания RPi 5 моментально перегреются и выгорят, а падение напряжения вызовет циклическую перезагрузку процессора (Brownout). Питание должно разветвляться строго **ДО** платы микрокомпьютера с помощью силовых полигонов типа «Звезда».

---

## РАЗДЕЛ 1. АРХИТЕКТУРА И ИЗОЛЯЦИЯ ПИТАНИЯ (УЗЕЛ 1)

Для обеспечения стабильной работы мы разделяем входное напряжение от официального блока питания 27W (5.1V / 5.0A) на два независимых плеча:
1.  **Логическое плечо (5.0V):** Питает Raspberry Pi 5 через специализированный «Идеальный диод» (MAX40200) для защиты от обратных токов и бросков напряжения.
2.  **Силовое плечо (8.0V):** Повышается с помощью DC-DC Step-Up модуля (XL6009/MT3608) для питания драйверов TC4427 и 5 силовых катушек базы.

### Схема разводки шин питания «Звезда»

```
                   ┌──────────────────────────────────┐
                   │    USB-C Breakout Board (5.1V IN)│
                   │     (Вход от адаптера 27W)       │
                   └─────────┬──────────────┬─────────┘
                             │ VBUS         │ GND
                             ▼              ▼
                    [ТОЛСТЫЙ ПРОВОД 18 AWG] [ТОЛСТЫЙ ПРОВОД 18 AWG]
                             │              │
       ┌─────────────────────┴──────┐       │   ┌───────────────────────────┐
       │                            │       ├───► [GND] Step-Up Модуля      │
       │                            │       │   └───────────────────────────┘
       ▼                            ▼       │   ┌───────────────────────────┐
┌──────────────┐             ┌────────────┐ ├───► [-] Конденсатора 2200uF    │
│  Идеальный   │             │  Step-Up   │ │   └───────────────────────────┘
│  Диод (IN)   │             │   (VIN+)   │ │   ┌───────────────────────────┐
└──────┬───────┘             └─────┬──────┘ ├───► [GND] Драйвера TC4427      │
       │ (OUT)                     │        │   └───────────────────────────┘
       ▼                           ▼ (8.0V) │   ┌───────────────────────────┐
 ┌────────────┐              ┌────────────┐ ├───► [GND] RP2040-Zero          │
 │Конденсатор │              │ [+] Силовой│ │   └───────────────────────────┘
 │1000uF 10V  │              │ Конденсатор│ │   ┌───────────────────────────┐
 └─────┬──────┘              │ 2200uF 16V │ ├───► [GPIO 6 (GND)] RPi 5       │
       │                     └─────┬──────┘ │   └───────────────────────────┘
       ▼                           │        ▼
┌──────────────┐                   │   ======================================
│GPIO 4 (5V)   │                   │   ЦЕНТРАЛЬНЫЙ СИЛОВОЙ ПОЛИГОН «GND ЗВЕЗДА»  
│Raspberry Pi 5│                   │   ======================================
└──────────────┘                   │
                                   ▼
                            ┌──────────────┐
                            │ ШИНА +8.0V   │ ──► На Пин 6 [VDD] TC4427
                            │ ДЛЯ КАТУШЕК  │ ──► На [+] контакты всех 5 катушек
                            └──────────────┘
```

*   **Настройка Step-Up модуля:** Перед впаиванием повышающего модуля в общую схему подключите его отдельно к 5V, возьмите мультиметр и вращением винта подстроечного потенциометра **жестко зафиксируйте выходное напряжение на уровне ровно 8.0V**.

## РАЗДЕЛ 2. СХЕМА ПОДКЛЮЧЕНИЯ СИЛОВОГО КАНАЛА (ПОВТОРИТЬ 5 РАЗ) (УЗЕЛ 2)

Каждая из пяти катушек базы управляется своим N-канальным MOSFET-транзистором AOD4184A через затворный драйвер TC4427. Параллельно выводам катушки впаивается быстродействующий диод SS54 (SMC) для защиты от импульсов самоиндукции.

### ⚡ Защита от ЭДС самоиндукции и TVS-фильтрация (Lenz Law Protection) - V4.0
При резкой коммутации токов катушек базы через диоды SS54 в силовой контур 8.0V может выбрасываться мощный индуктивный импульс самоиндукции ($V_{\text{kick}} = -L \cdot \frac{di}{dt}$). Для абсолютного поглощения этой энергии и защиты затворов MOSFET и Step-Up преобразователя, выполняются следующие требования:
1.  **Монтаж TVS-диода:** Параллельно силовой шине +8.0V и полигону GND «Звезда» в непосредственной близости от силового конденсатора 2200 мкФ впаивается защитный двунаправленный (или однонаправленный) TVS-диод **SMBJ12A** (или **SMBJ15A**). Он жестко срезает любые выбросы напряжения выше 12V-15V.
2.  **Защита логики RPi 5:** Идеальный диод MAX40200 гарантирует, что импульсные токи и выбросы силового плеча физически не смогут проникнуть в логические 5.1V Raspberry Pi 5.

```
                   [ ШИНА +8.0V ОТ STEP-UP ]
                             │
                             ├──────────────────────┐
                             │                      │
                             ▼                      ▼
                     ┌───────────────┐      ┌───────────────┐
                     │ Катушка GU22  │      │   Диод SS54   │
                     │  (Конец А)    │      │    (КАТОД)    │
                     └───────┬───────┘      └───────┬───────┘
                             │                      │
                             ├──────────────────────┘
                             │
                             ▼ (Точка соединения)
                             ├──────────────────────┐
                             │                      │
                             ▼                      ▼
                     ┌───────────────┐      ┌───────────────┐
                     │ Катушка GU22  │      │   Диод SS54   │
                     │  (Конец Б)    │      │    (АНОД)     │
                     └───────┬───────┘      └───────┬───────┘
                             │                      │
                             ├──────────────────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │  DRAIN (Сток)   │
                    │    AOD4184A     │
                    └────────┬────────┘
                             │
       ┌───────────[ GATE ]──┴──[ SOURCE (Исток) ]───────────┐
       │                                                     │
       ▼                                                     ▼
 ┌───────────┐                                      ===================
 │Резистор   │                                      СИЛОВАЯ ЗЕМЛЯ GND  
 │10 кОм     │                                           «ЗВЕЗДА»
 │Pull-down  │                                      ===================
 └─────┬─────┘                                               ▲
       │                                                     │
       └─────────────────────────────────────────────────────┘
```

*   **Правило монтажа диода SS54:** Припаивайте диоды защиты SS54 **вплотную к выводам Drain (Сток) и Source (Исток) транзисторов AOD4184A на плате**. Чем ближе диод к транзистору, тем эффективнее он гасит импульс и тем меньше электромагнитных помех излучается на ToF-датчик и датчики Холла.
*   **Pull-down резистор:** SMD-резистор 10 кОм припаивается непосредственно между ножками Gate и Source транзистора AOD4184A. Он гарантирует, что катушка будет 100% обесточена в момент включения питания.

## РАЗДЕЛ 3. КОММУТАЦИЯ ДРАЙВЕРА ЗАТВОРОВ (TC4427) И RP2040-ZERO (УЗЕЛ 3)

Запитка драйвера производится напрямую от **8.0V силовой линии**. Это позволяет подавать на затвор MOSFET жесткий 8-вольтовый импульс, переводя транзистор в полностью открытое состояние с минимальным внутренним сопротивлением. Ключи будут работать в идеально холодном режиме!

```
                  Микросхема TC4427 (SOIC-8)
                    ┌───────    ───────┐
            (NC) ───│ 1 (NC)    (NC) 8 │─── (NC)
                    │                  │
   [ШИМ RP2040] ───│ 2 (IN A)  (OUT A) 7 │───► [SMD 22 Ohm] ──► [GATE MOSFET 1]
                    │                  │
    [Star GND]  ───│ 3 (GND)    (VDD) 6 │───► [ШИНА +8.0V]
                    │                  │
   [ШИМ RP2040] ───│ 4 (IN B)  (OUT B) 5 │───► [SMD 22 Ohm] ──► [GATE MOSFET 2]
                    └──────────────────┘
```

*   **SMD Резистор 22 Ом:** Монтируется последовательно в разрыв цепи между выходом OUT драйвера и затвором MOSFET. Он гасит паразитный высокочастотный «звон» на затворе, защищая транзистор от выгорания.

## РАЗДЕЛ 4. ГЕОМЕТРИЯ СЕНСОРНОЙ ПАЛУБЫ БАЗЫ UNDER GU22-13

С переходом на увеличенные 22-мм чашки **GU22-13** центры боковых катушек раздвигаются, формируя новую геометрию:

```
                              ( North )
                              Coil 1 (22mm)
                                 [  ]
                                  │
                                  │ (27.0 mm Offset)
                                  │
                  ToF (X:28.0, Y:0) [ VL53L5CX ]
                                  │
                                  │   H2 [ ] (Hall 2 @ 45°)
                                  │  /
                                  │ / (15.5 mm Offset)
                                  │/
    ( West ) Coil 4 ── (27.0mm) ── [Center] ── (27.0mm) ── Coil 2 ( East )
     (22mm)    [  ]             Coil 0 (22mm)             [  ] (22mm)
                                  │                                  │ \ (15.5 mm Offset)
                                  │  H3 [ ] (Hall 3 @ 135°)
                                  │
                                  │ (27.0 mm Offset)
                                  │
                                 [  ]
                              Coil 3 (22mm)
                              ( South )
```

1.  **Центральная и боковые катушки:** Смещение центров катушек 1, 2, 3, 4 от центральной оси базы строго равно **`27.0 мм`**.
2.  **Датчики Холла SS49E:** Четыре аналоговых датчика располагаются на диагональных осях (45°, 135°, 225°, 315°) на расстоянии **`15.5 мм`** от абсолютного центра Базы.
3.  **ToF-матрица VL53L5CX:** Окно датчика располагается со смещением **`OFFSET_X_MM = 28.0 мм`**. В коде сервера это смещение автоматически компенсируется.
