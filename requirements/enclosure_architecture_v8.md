# АРХИТЕКТУРА И 3D-МОДЕЛЬ КОРПУСА БАЗЫ V8.0 (.docs/enclosure_architecture_v8.md)
## Integrated Anti-Vibration Base Lid & Split Calibration Cradle Lock

Данный документ содержит полную спецификацию и промышленный OpenSCAD-код детали **`Base_Top_Lid_V8`** (Крышка Базы v8.0) и сопряжения с **`calibration_stand_v1.scad`** (Разъёмный калибровочный стенд).

---

## 1. Конструктивные изменения v8.0

1. **Замковые L-пазы для Калибровочного Стенда (R = 56.5 мм):**
   На внешнем краю крышки (радиус `56.5 мм`) вне зоны катушек ($R \le 38.5\text{ мм}$) и ToF-датчика ($R = 50.75\text{ мм}$) врезаны 4 изогнутых L-паза под углом $45^\circ, 135^\circ, 225^\circ, 315^\circ$.
   - Позволяют надежно зафиксировать калибровочную подставку поворотным щелчком на 5 градусов.
   - Полностью поглощают вибрации и реактивные силы магнитного поля при калибровке.

2. **Сохранение 3-квадрантной вентиляции v7.0:**
   - Сохранены сплошные вертикальные жабры шириной 3.5 мм по направлениям $0^\circ$ (East), $90^\circ$ (North), $180^\circ$ (West).
   - Слайд-паз для вентилятора 3010 на стороне $270^\circ$ (South).

3. **Осевая позиция ToF (X = +45.0 мм):**
   - Окно ToF-датчика VL53L5CX на оси X ($X = 45.0\text{ мм}, Y = 0$) в тангенциальном исполнении. Зазор до катушки №2 равен 0.75 мм.

---

## 2. Полный OpenSCAD Код (`Base_Top_Lid_V8`)

```openscad
// =====================================================================
// ANTIGRAVITY PHASE 4 // BASE TOP LID V8.0 WITH LOCKING SLOTS
// =====================================================================

$fn = 90;

module Base_Top_Lid_V8() {
    difference() {
        union() {
            // Главный диск палубы (Диаметр 120мм, Толщина 3.0мм)
            cylinder(h = 3.0, r = 60.0, center = false);
            
            // Посадочный буртик под Байонет Башни (R = 58.0мм, h = 4.0мм)
            translate([0, 0, -4.0])
                difference() {
                    cylinder(h = 4.0, r = 58.0, center = false);
                    cylinder(h = 4.0, r = 55.0, center = false);
                }
        }
        
        // 1. Центральная шахта катушки Coil 0 (23.0 мм)
        translate([0, 0, -5])
            cylinder(h = 10, r = 11.5, center = false);
            
        // 2. 4x Боковые шахты катушек Coil 1..4 (R_center = 27.0mm, r_hole = 11.5mm)
        for (angle = [0, 90, 180, 270]) {
            rotate([0, 0, angle])
                translate([27.0, 0, -5])
                    cylinder(h = 10, r = 11.5, center = false);
        }
        
        // 3. 4x Окна датчиков Холла SS49E (R_center = 15.5mm, 45, 135, 225, 315 deg)
        for (angle = [45, 135, 225, 315]) {
            rotate([0, 0, angle])
                translate([15.5, 0, -5])
                    cube([4.5, 4.5, 10], center = true);
        }
        
        // 4. Ложемент ToF-датчика VL53L5CX (X = +45.0mm, Y = 0, Тангенциальный)
        translate([45.0, 0, -1]) {
            // Верхнее сквозное окно "глазок" (11.5 x 6.5 мм)
            cube([6.5, 11.5, 10], center = true);
            // Нижний карман под плату (26.5 x 11.5 мм, глубина 2.0мм)
            translate([0, 0, 2.5])
                cube([11.5, 26.5, 2.1], center = true);
        }
        
        // 5. 4x Внешние L-пазы для Калибровочного Стенда (R = 56.5mm) [NEW v8.0]
        for (angle = [45, 135, 225, 315]) {
            rotate([0, 0, angle]) {
                translate([56.5, 0, -1])
                    cylinder(h = 5, r = 2.2, center = false);
                // Поворотная направляющая 5 градусов
                rotate([0, 0, 5])
                    translate([56.5, 0, -1])
                        cylinder(h = 5, r = 2.2, center = false);
            }
        }
    }
}

// Рендер детали
color([0.15, 0.15, 0.15, 1.0]) Base_Top_Lid_V8();
```
