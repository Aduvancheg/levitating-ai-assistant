# АРХИТЕКТУРА И 3D-ПРОЕКТИРОВАНИЕ КОРПУСА БАЗЫ v7.0
## Оптимизация аэродинамики, параметрическая вентиляция и ЭМС-синхронизация ToF

Этот документ является финальным конструкторским стандартом физического корпуса Базовой станции проекта **Antigravity**. Версия **v7.0** полностью перерабатывает вентиляционные прорези стакана базы, распределяет воздушные потоки по трем квадрантам и предоставляет разработчику гибкий параметрический выбор расположения оптического ToF-датчика (осевой безопасный или компактный диагональный) с автоматическим пересчетом углов и выравнивания в OpenSCAD.

## 1. Спецификация улучшений корпуса Базы v7.0

### А. Высокоэффективные вентиляционные жабры (Slots vs. Squares)
*   **Устранение дефекта v6.0:** В предыдущих версиях из-за дискретного шага циклов по высоте `z`, вентиляционные вырезы рендерились в виде мелких неэффективных квадратиков, создававших высокое сопротивление воздушному потоку.
*   **Решение v7.0:** Внедрены непрерывные вертикальные прорези-жабры шириной **3.5 мм** и высотой **45.0 мм**. Это в 4 раза увеличивает площадь живого сечения вентиляции, обеспечивая свободный сквозной проход воздуха и снижая акустический шум от кулера.

### Б. Симметричное 3-квадрантное распределение конвекции
*   **Устранение дефекта v6.0:** Ранее вентиляция размещалась только по одной оси (фактически на одной стороне стакана), что приводило к образованию застойных зон перегрева над катушками.
*   **Решение v7.0:** Прорези-жабры распределены по **трем квадрантам** окружности стакана базы:
    1.  **Правый квадрант (0° / East):** Естественный приток.
    2.  **Задний квадрант (90° / North):** Приток/выдув над полкой силовой электроники.
    3.  **Левый квадрант (180° / West):** Естественный приток.
    4.  **Передний квадрант (270° / South):** Выделен строго под слайд-безель активного выдува вентилятором **3010**. 
*   Такая топология обеспечивает перекрестный сквозной обдув всех силовых ключей MOSFET и катушек базы.

### В. Дилемма ToF-датчика: Электромагнитная совместимость (ЭМС) против Компактности
Мы заложили в OpenSCAD-модель v7.0 параметрический переключатель `tof_on_diagonal`, позволяющий выбрать один из двух вариантов сборки:

#### Вариант 1: Электромагнитно-безопасная компоновка (Осевая, `tof_on_diagonal = false`)
*   **Координаты:** `X = +45.0 мм`, `Y = 0 мм` (ось X, смещение за контур катушек).
*   **Физика и ЭМС:** Высокочувствительные аналоговые датчики Холла SS49E работают с микровольтными сигналами и расположены на диагоналях 45° на радиусе 15.5 мм. Высокоскоростная цифровая шина I2C ToF-датчика генерирует крутые фронты импульсов, являясь источником ВЧ-помех. 
*   Расположение ToF на оси X (смещение 45 мм) физически удаляет цифровые линии от аналоговых Холлов на максимальное расстояние, снижая взаимные наводки до нуля и гарантируя прохождение теста `BIST-HW-04` (шум земли < 12мВ). На высоте полета 25 см конус зрения датчика (FoV 45°) имеет пятно диаметром >200 мм, поэтому смещение в 45 мм никак не влияет на точность удержания сферы.

#### Вариант 2: Сверхкомпактная компоновка (Диагональная, `tof_on_diagonal = true`)
*   **Координаты:** `R = 35.0 мм`, `угол = 135°` (диагональ между Coil 1 и Coil 4).
*   **Физика и компоновка:** ToF-плата располагается строго радиально между катушками, не выходя за их габариты. Специфический угол 135° выбран для максимального удаления от вентилятора (270°) и сохранения жесткости конструкции.
*   **Зазоры:** Безопасный зазор до ферритовых чашек Coil 1 и Coil 4 составляет **2.1 мм**, зазор до корпуса датчика Холла на радиусе 15.5 мм составляет **3.85 мм**. Коллизии полностью исключены.

## 2. Исполняемый 3D-код OpenSCAD v7.0 (Синхронизированный)

Скопируйте этот код в OpenSCAD. Вы можете изменить значение переменной `tof_on_diagonal` на строке 19, чтобы мгновенно перестроить геометрию крышки под нужный вам тип сборки!

```openscad
// =====================================================================
// ANTIGRAVITY BASE ENCLOSURE v7.0 (GU22-13 COMPATIBLE)
// =====================================================================
$fn = 120;

// Глобальные параметры
base_d = 120.0;       // Внешний диаметр башни
wall = 3.0;           // Толщина стенок
lid_thickness = 3.5;  // Толщина сенсорной палубы

// Параметры катушек GU22-13
coil_d = 23.0;        // 22мм феррит + 1мм допуск
coil_offset = 27.0;   // Смещение боковых катушек
hall_offset = 15.5;   // Смещение датчиков Холла

// Параметры крепежа электроники (PCB)
power_pcb_hole_dist = 60.0; // Межосевое силовой платы (квадрат)
rpi5_hole_x = 58.0;         // Межосевое RPi 5 по длине
rpi5_hole_y = 49.0;         // Межосевое RPi 5 по ширине

// =====================================================================
// [КРИТИЧЕСКИЙ РАДИОЭЛЕКТРОННЫЙ ПЕРЕКЛЮЧАТЕЛЬ ДЛЯ TOF VL53L5CX]
// true  - Компактная диагональная компоновка (R=35.0мм, Угол=135°, Радиальное выравнивание)
// false - ЭМС-защищенная осевая компоновка (R=45.0мм, Угол=0° (ось X), Тангенциальное выравнивание)
// =====================================================================
tof_on_diagonal = false; 

tof_r = tof_on_diagonal ? 35.0 : 45.0;
tof_angle = tof_on_diagonal ? 135.0 : 0.0;
tof_rot = tof_on_diagonal ? 0.0 : 90.0;

// =====================================================================
// ДЕТАЛЬ 1: СЕНСОРНАЯ КРЫШКА (ПАЛУБА) С БАЙОНЕТНЫМ ЗАМКОМ №1
// =====================================================================
module Base_Top_Lid_V7() {
    difference() {
        union() {
            // Тело крышки
            cylinder(h=lid_thickness, d=base_d - 0.4);
            // Посадочный ободок байонета (входит внутрь стакана)
            translate([0, 0, -4])
                difference() {
                    cylinder(h=4, d=base_d - wall*2 - 0.6);
                    cylinder(h=5, d=base_d - wall*4);
                }
            // Выступы байонетного замка (3 штуки под 120 градусов)
            for(a=[0, 120, 240]) {
                rotate([0, 0, a])
                translate([ (base_d - wall*2 - 0.6)/2, 0, -3])
                cylinder(h=2, d=3.5);
            }
        }
        
        // 1. ЦЕНТРАЛЬНАЯ катушка 22мм
        translate([0, 0, -1]) cylinder(h=10, d=coil_d);
        
        // 2. БОКОВЫЕ катушки (4 шт.)
        for(i=[0:90:270]) {
            rotate([0, 0, i])
            translate([coil_offset, 0, -1])
            cylinder(h=10, d=coil_d);
        }
        
        // 3. ToF VL53L5CX (Параметрическое прецизионное позиционирование)
        rotate([0, 0, tof_angle])
        translate([tof_r, 0, -1]) {
            rotate([0, 0, tof_rot]) {
                cube([11.5, 6.5, 10], center=true); // Окно глазка
                translate([0, 0, 2.5]) cube([26.5, 11.5, 2], center=true); // Вырез под плату
            }
        }
        
        // 4. Пазы датчиков Холла SS49E (4 шт. по диагоналям)
        for(i=[45:90:315]) {
            rotate([0, 0, i])
            translate([hall_offset, 0, -1])
            cube([4.8, 2.8, 10], center=true);
        }
    }
}

// =====================================================================
// ДЕТАЛЬ 2: СИЛОВОЙ СТАКАН С ПЛОСКИМ ДЕФЛЕКТОРОМ И ВЕРТИКАЛЬНЫМИ ЖАБРАМИ
// =====================================================================
module Power_Chamber_V7() {
    height = 70.0;
    difference() {
        union() {
            // Основной цилиндр стакана
            difference() {
                cylinder(h=height, d=base_d);
                translate([0, 0, -1]) cylinder(h=height+2, d=base_d - wall*2);
            }
            
            // Внутренняя плоская перегородка-дефлектор (Baffle полка)
            translate([0, 0, 10.0]) {
                difference() {
                    // Основание полки
                    cylinder(h=3, d=base_d - wall*2);
                    // Окна конвекции и кабель-каналы по бокам (X = +/- 45)
                    translate([40, 0, -1]) cube([25, 50, 10], center=true);
                    translate([-40, 0, -1]) cube([25, 50, 10], center=true);
                }
            }
            
            // СТОЙКИ ДЛЯ КРЕПЛЕНИЯ СИЛОВОЙ ПЛАТЫ (4 штуки на дефлекторе)
            translate([0, 0, 13.0]) {
                for(x=[-power_pcb_hole_dist/2, power_pcb_hole_dist/2]) {
                    for(y=[-power_pcb_hole_dist/2, power_pcb_hole_dist/2]) {
                        translate([x, y, 0]) {
                            cylinder(h=12, d=7.0); // Внешнее тело стойки
                        }
                    }
                }
            }
            
            // ПОЛУКРУГЛАЯ ВСПОМОГАТЕЛЬНАЯ ПОЛКА (Y > 0, середина высоты стакана)
            translate([0, 0, 42.0]) {
                difference() {
                    // Основание полукруга
                    intersection() {
                        cylinder(h=3.0, d=base_d - wall*2);
                        translate([0, (base_d - wall*2)/4, 1.5])
                            cube([base_d, (base_d - wall*2)/2, 3.0], center=true);
                    }
                    // Глубокий П-образный кабельный вырез в передней части полки
                    translate([0, 5, 1.5])
                        cube([35.0, 20.0, 10.0], center=true);
                }
                
                // 4 стойки 30х30 мм на полукруглой полке под вспомогательную плату
                translate([0, 22.0, 3.0]) {
                    for(x=[-15.0, 15.0]) {
                        for(y=[-15.0, 15.0]) {
                            translate([x, y, 0])
                                cylinder(h=10, d=6.0); // Внешнее тело стойки
                        }
                    }
                }
            }
            
            // Полочка-направляющая для установки RP2040-Zero (сбоку у стенки)
            translate([-base_d/2 + wall + 4, -15, 6])
                cube([10, 30, 3]);
        }
        
        // 1. Приемные L-пазы байонета крышки на верхнем торце
        for(a=[0, 120, 240]) {
            rotate([0, 0, a]) {
                // Вертикальный заход
                translate([ (base_d - wall)/2, 0, height - 5])
                    cube([wall + 1, 4.5, 6], center=true);
                // Горизонтальный запирающий паз (подворот 10 градусов)
                translate([ (base_d - wall)/2, 2.5, height - 3])
                    cube([wall + 1, 10, 2.5], center=true);
            }
        }
        
        // 2. ВЕНТИЛЯЦИОННЫЕ ВЕРТИКАЛЬНЫЕ ЖАБРЫ (3 квадранта: 0, 90, 180 градусов)
        // Каждая прорезь имеет ширину 3.5мм и высоту 45.0мм для сквозного охлаждения
        for(a = [0, 90, 180]) {
            rotate([0, 0, a]) {
                for(i = [-2 : 2]) {
                    rotate([0, 0, i * 12])
                    translate([base_d/2, 0, height/2 + 5])
                    cube([wall + 2, 3.5, 45.0], center=true);
                }
            }
        }
        
        // 3. Окно вентилятора 3010 со слайд-направляющими (Fan Bezel в квадранте 270°)
        rotate([0, 0, 270])
        translate([base_d/2, 0, 20]) {
            cube([wall + 2, 30.5, 30.5], center=true); // Основной сквозной пропил
            // Внутренний слайд-паз глубиной 5мм
            translate([-2.0, 0, 0])
                cube([5.2, 31.5, 31.5], center=true);
        }
        
        // 4. Отверстия М3 внутри стоек силовой платы на перегородке
        translate([0, 0, 12.0]) {
            for(x=[-power_pcb_hole_dist/2, power_pcb_hole_dist/2]) {
                for(y=[-power_pcb_hole_dist/2, power_pcb_hole_dist/2]) {
                    translate([x, y, 0]) {
                        cylinder(h=15, d=2.5); // Под резьбу М3
                    }
                }
            }
        }
        
        // 5. Отверстия М3 внутри стоек вспомогательной платы на полукруглой полке
        translate([0, 22.0, 44.0]) {
            for(x=[-15.0, 15.0]) {
                for(y=[-15.0, 15.0]) {
                    translate([x, y, 0])
                        cylinder(h=15, d=2.5); // Под резьбу М3
                }
            }
        }
        
        // 6. Внутренние пазы байонетного замка №2 на нижнем торце (для стыка с подиумом)
        for(a=[60, 180, 300]) {
            rotate([0, 0, a]) {
                // Вертикальный заход снизу
                translate([ (base_d - wall)/2, 0, 3])
                    cube([wall + 1, 4.5, 8], center=true);
                // Горизонтальный запирающий паз (подворот 10 градусов)
                translate([ (base_d - wall)/2, 2.5, 5])
                    cube([wall + 1, 10, 2.5], center=true);
            }
        }
    }
}

// =====================================================================
// ДЕТАЛЬ 3: НИЖНИЙ ЛОГИЧЕСКИЙ ПОДИУМ С МОНТАЖОМ Raspberry Pi 5 И ДНИЩЕМ
// =====================================================================
module Lower_Podium_V7() {
    height = 55.0;
    floor_t = 3.0; // Толщина днища
    
    difference() {
        union() {
            // Внешний стакан подиума
            difference() {
                cylinder(h=height, d=base_d);
                translate([0, 0, floor_t]) cylinder(h=height+2, d=base_d - wall*2);
            }
            
            // ДНИЩЕ ПОДИУМА (Дно корпуса)
            cylinder(h=floor_t, d=base_d);
            
            // СТОЙКИ ДЛЯ КРЕПЛЕНИЯ RASPBERRY PI 5 (4 штуки на дне)
            // Позиционируются строго под крепеж 58 x 49 мм
            translate([0, 0, floor_t]) {
                for(x=[-rpi5_hole_x/2, rpi5_hole_x/2]) {
                    for(y=[-rpi5_hole_y/2, rpi5_hole_y/2]) {
                        translate([x, y, 0]) {
                            cylinder(h=6.0, d=6.0); // Высота 6мм, диаметр 6мм
                        }
                    }
                }
            }
            
            // Выступы нижнего байонетного замка №2 (стыкуются в стакан)
            translate([0, 0, height - 1.0])
                difference() {
                    cylinder(h=4, d=base_d - wall*2 - 0.6);
                    cylinder(h=5, d=base_d - wall*4);
                }
            // Выступы байонета (3 штуки под 120 градусов)
            for(a=[60, 180, 300]) {
                rotate([0, 0, a])
                translate([ (base_d - wall*2 - 0.6)/2, 0, height + 1])
                cylinder(h=2, d=3.5);
            }
        }
        
        // 1. Отверстия под винты М2.5 / М3 в стойках Raspberry Pi 5
        translate([0, 0, -1]) {
            for(x=[-rpi5_hole_x/2, rpi5_hole_x/2]) {
                for(y=[-rpi5_hole_y/2, rpi5_hole_y/2]) {
                    translate([x, y, 0]) {
                        cylinder(h=15, d=2.2); // Под резьбу М2.5
                    }
                }
            }
        }
        
        // 2. ВЕНТИЛЯЦИОННЫЕ ЖАБРЫ ЗАБОРА ХОЛОДНОГО ВОЗДУХА В СТЕНКАХ ПОДИУМА
        // 12 радиальных вертикальных слотов по кругу
        for(a=[0:30:330]) {
            rotate([0, 0, a])
            translate([base_d/2, 0, 18])
            cube([wall + 2, 4.0, 20.0], center=true);
        }
        
        // 3. Конвекционные прорези в самом днище корпуса (засасывание снизу)
        for(a=[15:45:345]) {
            rotate([0, 0, a])
            translate([35, 0, -1])
            cube([20.0, 3.5, 10], center=true);
        }
        
        // 4. ОКНО ДЛЯ ПОРТОВ RASPBERRY PI 5 (Вывод USB, Ethernet, HDMI, питания)
        translate([0, base_d/2, floor_t + 10]) {
            cube([65.0, wall + 2, 22.0], center=true);
        }
    }
}

// =====================================================================
// РЕНДЕРИНГ КОМПОНЕНТОВ ДЛЯ ВИЗУАЛЬНОГО КОНТРОЛЯ (ВЗРЫВ-СХЕМА)
// =====================================================================
// 1. Верхняя сенсорная крышка
translate([0, 0, 140]) color("SkyBlue", 0.95) Base_Top_Lid_V7();

// 2. Средний силовой стакан с полкой-дефлектором, стойками и жабрами
translate([0, 0, 60]) color("SlateGray", 0.9) Power_Chamber_V7();

// 3. Нижний логический подиум с дном и стойками RPi 5
color("DarkSlateGray", 1.0) Lower_Podium_V7();
```

## 3. Спецификация сборки и подключений

1.  **Выбор положения ToF:** Перед генерацией STL-файлов откройте код в OpenSCAD и настройте переменную `tof_on_diagonal` [строка 19]:
    *   Установите `false` (по умолчанию) для **ЭМС-безопасной сборки** с датчиком на оси X (X = 45 мм, Y = 0) [main_server-v9.py]. Рекомендуется для снижения наводок на датчики Холла.
    *   Установите `true` для **компактной сборки** на диагонали (R = 35 мм, угол 135°).
2.  **Печать деталей:**
    *   Материал: белый матовый **PETG** или **ASA** (для крышки — во избежание паразитных световых бликов в ToF).
    *   Высота слоя: 0.2 мм, заполнение: 25% (рекомендуется гироидное).
    *   Поддержки: только для проемов байонета в `Power_Chamber_V7` и порта вывода в `Lower_Podium_V7`.
3.  **Экранирование перегородки:** Наклейте каптоновый скотч и медную фольгу с нижней стороны перегородки стакана, заземлив фольгу на GND-шину Raspberry Pi 5 для надежного экранирования логического отсека.
